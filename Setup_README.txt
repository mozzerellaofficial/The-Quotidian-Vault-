=========================================================

Welcome to The Quotidian Vault! 

Double-click the "The Quotidian Vault Setup 1.0.0.exe" file to 
install the application.

---------------------------------------------------------
TROUBLESHOOTING: "WINDOWS PROTECTED YOUR PC"
---------------------------------------------------------
Because this is a brand new privacy application, Windows SmartScreen 
might display a blue popup saying "Windows protected your PC".

To proceed with the installation safely:
1. Click the "More info" text link under the warning message.
2. A new button will appear at the bottom right.
3. Click "Run anyway".

If you are using Windows 11 Smart App Control and it is completely 
blocking the file without a "Run anyway" option:
1. Right-click the Setup .exe file.
2. Select "Properties".
3. Check the "Unblock" box at the bottom of the General tab.
4. Click Apply, then OK, and double-click to install.

---------------------------------------------------------
WHAT IF I CANNOT UNINSTALL AN OLD VERSION?
---------------------------------------------------------
If Windows is preventing you from uninstalling a previous version 
of The Quotidian Vault, please return to our website:
https://the-quotidian-vault.pages.dev/

Click the "Download for Windows" button, and select the red 
"Download Emergency Uninstaller" option. That tool will clean 
your system so you can install this new version perfectly!
